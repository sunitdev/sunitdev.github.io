# Self-hosted journal fonts

Downloaded from the official google/fonts repository on 2026-10-01. Original fonts are distributed under the included SIL Open Font Licenses. WOFF2 files are compressed copies made with FontTools.

- instrument-serif: https://github.com/google/fonts/tree/main/ofl/instrumentserif
- source-serif-4: https://github.com/google/fonts/tree/main/ofl/sourceserif4
- ibm-plex-mono: https://github.com/google/fonts/tree/main/ofl/ibmplexmono

Instrument Serif and Source Serif 4 are subsetted for Latin, Greek, punctuation, and math symbols. IBM Plex Mono preserves the original glyph set and font data, with WOFF2 compression only.
